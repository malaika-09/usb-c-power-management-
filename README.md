## 📋 Overview

This repository contains comprehensive technical documentation for a **USB-C Power Management System** with integrated **USB 3.0 Hub Controller**. 

### Key Features:
- ⚡ USB-C Power Delivery (5V-20V, up to 100W)
- 🔌 USB 3.0 Hub with 4-7 downstream ports
- 🛡️ Complete protection (OCP, OVP, ESD, Thermal)
- 📐 4-layer PCB design with controlled impedance
- 🎨 Professional documentation with dark theme

## 🔧 Technical Highlights

| Feature | Specification |
|---------|---------------|
| **Power Input** | USB-C PD (5V-20V, up to 100W) |
| **Power Output** | 5V @ 3A, 3.3V @ 1.5A, 1.8V @ 500mA |
| **USB Hub** | USB 3.0 SuperSpeed (5 Gbps) |
| **Ports** | 4-7 downstream USB Type-A ports |
| **PCB Layers** | 4-layer board (Signal/GND/PWR/Signal) |
| **Protection** | OCP, OVP, ESD, Thermal shutdown |
| **Design Tool** | KiCad 7.x/8.x |
