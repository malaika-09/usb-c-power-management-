█████ STEP 1: OPEN TERMINAL (10 seconds)
═════════════════════════════════════════
Right-click on "Project_Documentation" folder
→ "Open in Terminal" or "Git Bash Here"


█████ STEP 2: COPY-PASTE THESE COMMANDS (2 minutes)
════════════════════════════════════════════════════

git init
git add .
git commit -m "USB-C Power Management Documentation"


█████ STEP 3: CREATE GITHUB REPO (1 minute)
════════════════════════════════════════════
1. Browser me jao: github.com/new
2. Name: usb-c-power-management
3. Public
4. Create repository
5. Copy the URL shown (looks like):
   https://github.com/YOUR_USERNAME/usb-c-power-management.git


█████ STEP 4: PUSH TO GITHUB (30 seconds)
══════════════════════════════════════════

# Replace YOUR_USERNAME with your actual GitHub username
git remote add origin https://github.com/YOUR_USERNAME/usb-c-power-management.git
git branch -M main
git push -u origin main


█████ STEP 5: DEPLOY ON VERCEL (1 minute)
══════════════════════════════════════════
1. vercel.com/dashboard
2. "Add New" → "Project"
3. "Import" your repository
4. "Deploy"
5. DONE! 🎉
