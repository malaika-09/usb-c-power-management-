⚡ Power Management Circuit

Voltage Regulation & Distribution

📋 System Overview

Function: Multi-rail power supply with efficient voltage regulation

Purpose: Convert USB-C PD input to multiple regulated output voltages for USB hub and downstream ports

Architecture: Buck converters and LDOs for different voltage rails

📸 Power Management Schematic

Figure 1: Complete power management and voltage regulation circuitry

🔋 Voltage Rails

🔴 5V Rail (Main Supply)

Output Voltage: 5.0V ± 2%

Maximum Current: 3A

Topology: Buck converter (step-down from PD input)

Load: USB hub controller, downstream port power

🟡 3.3V Rail (Logic Supply)

Output Voltage: 3.3V ± 3%

Maximum Current: 1.5A

Topology: LDO or buck converter from 5V

Load: Digital logic, microcontroller, I/O interfaces

🟢 1.8V Rail (Low Voltage Logic)

Output Voltage: 1.8V ± 3%

Maximum Current: 500mA

Topology: LDO from 3.3V

Load: Core logic, optional peripherals

🎯 Key Features

⚙️ Efficiency

  • High-efficiency buck converters (>90%)
  • Low quiescent current LDOs
  • Synchronous rectification

🛡️ Protection

  • Over-current protection (OCP)
  • Over-voltage protection (OVP)
  • Thermal shutdown (TSD)
  • Short-circuit protection

📊 Monitoring

  • Power-good signals
  • Enable/disable control
  • Voltage monitoring points

🔧 Control

  • Soft-start circuitry
  • Sequencing capability
  • Adjustable output voltage

🔌 Power Distribution

Input Power:

  • Source: USB-C PD (5V-20V, negotiated)
  • Typical Input: 12V or 15V profile

Output Distribution:

  • 5V → USB Hub Controller, Downstream USB ports
  • 3.3V → Hub logic, control circuits
  • 1.8V → Core logic (if required)

📐 Design Specifications

  • Total Power Budget: Up to 60W (from USB PD)
  • Number of Rails: 3 main voltage rails (5V, 3.3V, 1.8V)
  • Load Regulation: <1% line regulation
  • Ripple & Noise: <50mV peak-to-peak
  • Transient Response: <50µs settling time
  • Operating Temperature: -40°C to +85°C

🔗 Interconnections

Input Connections:

  • VBUS from USB-C PD Input module
  • Enable signals from system controller

Output Connections:

  • 5V to Hub Controller module
  • 5V to Downstream Ports module
  • 3.3V to Hub Controller logic
  • Power-good signals to system
