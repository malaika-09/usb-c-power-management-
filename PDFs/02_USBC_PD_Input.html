📥 USB-C PD Input Circuit

Power Delivery Input Stage

📋 Circuit Overview

Function: USB-C Power Delivery input interface and negotiation

Purpose: Accepts USB-C PD input, negotiates power profiles, and provides regulated input to power management stage

Key Components: USB-C connector, CC communication, PD controller

📸 Schematic Diagram

Figure 1: USB-C PD input circuit with CC lines and configuration

⚡ Technical Specifications

Parameter Specification
Connector Type USB Type-C (24-pin)
Power Delivery Version USB PD 2.0/3.0 compatible
Input Voltage Range 5V - 20V (USB PD profiles)
Maximum Current Up to 5A (100W capability)
CC Communication Configuration Channel for PD negotiation
Protection Overvoltage, overcurrent, ESD protection

🎯 Key Features

  • USB-C Compatibility: Reversible connector with full PD support
  • Power Profiles: Supports multiple voltage/current combinations (5V/3A, 9V/3A, 12V/3A, 15V/3A, 20V/5A)
  • CC Line Configuration: Proper CC resistor configuration for power negotiation
  • VBUS Monitoring: Real-time voltage and current monitoring
  • Hot-plug Support: Safe connection and disconnection

🔌 Connection Points

Inputs:

  • USB-C VBUS (Power input)
  • CC1, CC2 (Configuration channels)
  • USB 2.0 D+/D- (Optional data lines)

Outputs:

  • Regulated VBUS to Power Management module
  • PD Status signals

🛡️ Protection Features

  • Overvoltage protection (OVP)
  • Overcurrent protection (OCP)
  • ESD protection on all USB-C pins
  • Reverse polarity protection
  • Thermal shutdown
