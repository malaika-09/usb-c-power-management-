🔗 Downstream USB Ports

USB Output Port Configuration & Protection

📋 Module Overview

Function: Physical USB port implementation with power switching and protection

Purpose: Provides safe, controlled power and data connections for downstream USB devices

Components: USB connectors, power switches, protection circuits, ESD protection

📸 Downstream Ports Schematic

Figure 1: Downstream USB port circuits with individual power control and protection

🔌 Port Architecture

Port 1-4: USB 3.0 Type-A Connectors

Connector Type: USB 3.0 Type-A female (9-pin)

Data Support: USB 3.0 SuperSpeed (5 Gbps) + USB 2.0 fallback

Power Capability: 5V @ 1.5A per port (max)

Pin Configuration:
  • VBUS (Pin 1) - 5V power output with switching
  • D- (Pin 2) - USB 2.0 data negative
  • D+ (Pin 3) - USB 2.0 data positive
  • GND (Pin 4) - Ground reference
  • SSTX+/- (Pins 5,6) - SuperSpeed transmit pair
  • SSRX+/- (Pins 8,9) - SuperSpeed receive pair
  • Shield - ESD protection to chassis ground

⚡ Power Distribution & Control

Power Switching Features:

  • Individual Control: Each port has independent power switch
  • Current Limiting: 1.5A limit per port (adjustable)
  • Soft-Start: Inrush current limiting on power-up
  • Fast Switching: Quick response to hub controller commands

Control Signals:

  • PORT_PWR_EN[1-4] - Enable/disable signals from hub controller
  • PORT_FAULT[1-4] - Overcurrent fault status to hub controller

🛡️ Protection Circuitry

Per-Port Protection:

  • Overcurrent Protection: 1.5A limit with automatic shutdown and fault reporting
  • ESD Protection: TVS diodes on all data lines (D+, D-, SSTX, SSRX)
  • Short-Circuit Protection: Fast current limit response
  • Reverse Current Protection: Prevents backfeeding
  • Thermal Protection: Power switch thermal shutdown

📊 Electrical Specifications

Power Specifications:

  • Output Voltage: 5.0V ± 5% (4.75V - 5.25V per USB spec)
  • Current per Port: Up to 1.5A (USB 3.0 specification)
  • Total Power Budget: 6A across all 4 ports (managed)
  • Voltage Drop: <100mV at full load

Data Specifications:

  • USB 3.0 Rate: 5 Gbps (SuperSpeed)
  • USB 2.0 Rate: 480 Mbps (High-Speed)
  • Impedance: 90Ω differential (USB 3.0), 90Ω differential (USB 2.0)
  • Signal Integrity: Series termination on all data lines

🔧 Component Details

Key Components per Port:

  • USB Connector: USB 3.0 Type-A receptacle
  • Power Switch: High-side load switch with current limit
  • ESD Protection: Low-capacitance TVS diode arrays
  • Status LED: Power/activity indicator (optional)
  • Decoupling: Bulk + ceramic capacitors near connector
  • Series Resistors: 22-33Ω on SSTX/SSRX for signal integrity

🔗 Connections

From Hub Controller Module:

  • USB 3.0 data lanes (SSTX/SSRX pairs for each port)
  • USB 2.0 data lines (D+/D- for each port)
  • Port power enable signals
  • Overcurrent fault inputs

From Power Management Module:

  • 5V main rail for port power
  • 3.3V for power switch logic

To External Devices:

  • USB Type-A connectors for device connection
  • Mounting holes for mechanical stability

🎯 Design Features

  • ✅ Hot-plug capable - safe insertion and removal
  • ✅ Automatic device detection
  • ✅ Individual port control from hub controller
  • ✅ Fault reporting and recovery
  • ✅ LED indicators for port status (optional)
  • ✅ Proper impedance matching for high-speed signals
  • ✅ Common-mode choke filtering for EMI reduction

📐 PCB Layout Considerations

  • Differential pair routing for USB 3.0 (SSTX, SSRX)
  • Controlled impedance traces (90Ω differential)
  • Length matching within pairs (<5 mils difference)
  • Ground plane underneath USB traces
  • Keep power and data lines separated
  • ESD protection placed close to connectors
  • Star ground configuration for clean return paths
